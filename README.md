# 소개팅 장소 자동 탐색 에이전트

사용자 취향에 맞는 소개팅 장소를 네이버지도에서 자동으로 탐색하고, 후보 장소를 점수화해 리포트로 정리해주는 AI 에이전트 프로젝트.

자세한 아이디어는 [idea.md](./idea.md)를 참고함.

## MVP 목표

초기 MVP의 목표는 완성된 서비스 전체를 만드는 것이 아니라, 핵심 가설을 빠르게 검증하는 것임.

우선 검증할 핵심은 다음과 같음.

- Playwright로 네이버지도 장소 탐색이 가능한지
- 장소별 사진과 리뷰를 수집할 수 있는지
- 수집한 사진과 리뷰를 기반으로 소개팅 적합도를 점수화할 수 있는지
- 점수화 결과를 리포트 형태로 저장할 수 있는지
- 이후 React UI와 FastAPI 서버를 붙일 수 있는 구조인지

## MVP 진행 범위

우선 아래 6단계까지 진행함.

### 1. MVP 문서 작성

`mvp.md`를 작성해 첫 MVP에서 만들 기능과 제외할 기능을 정리함.

정리할 내용:

- MVP 목표
- 사용자 입력값
- 에이전트 실행 흐름
- 장소 분석 기준
- 리포트에 포함할 정보
- 이번 MVP에서 제외할 기능

### 2. Playwright 네이버지도 탐색 POC

Python + Playwright로 네이버지도 탐색이 가능한지 먼저 확인함.

검증할 내용:

- 검색어로 네이버지도 진입
- 특정 역 또는 지역 기준 장소 검색
- 검색 결과 목록 접근
- 장소 상세 화면 진입
- 장소명, 카테고리, 주소 등 기본 정보 추출 가능 여부

### 3. 장소 데이터 모델 정의

에이전트 내부에서 사용할 장소 데이터 구조를 정의함.

포함할 정보:

- 장소명
- 주소
- 카테고리
- 네이버지도 URL
- 리뷰 수
- 사진 목록
- 리뷰 목록
- 필터링 결과
- 사진 점수
- 리뷰 점수
- 최종 점수
- 판단 근거

### 4. 서브 에이전트 점수화 로직 작성

개별 장소를 분석하는 서브 에이전트 로직을 작성함.

처리 흐름:

1. 사전 필터링 조건 확인
2. 조건 미달 시 제외 사유 반환
3. 조건 통과 시 사진 분석
4. 리뷰 분석
5. 사진 점수와 리뷰 점수를 종합해 최종 점수 계산
6. 판단 근거 생성

### 5. Markdown/HTML 리포트 생성

분석 결과를 사람이 보기 쉬운 리포트로 저장함.

리포트에 포함할 내용:

- 점수 높은 순 장소 목록
- 장소별 최종 점수
- 사진 기반 평가
- 리뷰 기반 평가
- 주요 판단 근거
- 필터링으로 제외된 장소와 제외 사유

초기에는 Markdown 리포트를 우선 만들고, 필요하면 HTML 리포트로 확장함.

### 6. FastAPI 서버 연결

CLI로 동작하던 에이전트를 FastAPI 서버에서 실행할 수 있게 연결함.

목표:

- 에이전트 실행 API 제공
- 실행 상태 조회 API 제공
- 리포트 조회 API 제공
- 이후 React 클라이언트와 연결 가능한 구조 마련

## 이번 MVP에서 제외할 것

초기 MVP에서는 핵심 검증에 집중하기 위해 아래 기능은 제외함.

- 로그인/회원가입
- 사용자별 인박스
- 고도화된 취향 프리셋
- 완성도 높은 실시간 브라우저 스트리밍
- 대규모 장소 탐색
- 배포 환경 구성
- 결제 또는 공유 기능

## 기술 방향

- client: React
- backend/agent: Python
- API server: FastAPI
- agent framework: LangChain, LangGraph
- browser automation: Playwright
- report: Markdown 우선, 이후 HTML 확장

## 개발 순서

1. `mvp.md` 작성
2. Playwright 탐색 POC 작성
3. 장소 데이터 모델 정의
4. 서브 에이전트 점수화 로직 작성
5. Markdown/HTML 리포트 생성
6. FastAPI 서버 연결

이후 단계에서 React UI, 실시간 진행 로그, 브라우저 스트리밍, 인박스 저장 기능을 순차적으로 붙임.
